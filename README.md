📋 Clipboard Landing Page
Este projeto é uma solução para o desafio Clipboard landing page da plataforma Frontend Mentor. O objetivo foi desenvolver uma página responsiva com base em um design proposto, praticando HTML, CSS e responsividade.

🚀 Tecnologias usadas
HTML5
CSS3 (com Flexbox)
Design responsivo com media queries

🎯 Desafio
Reproduzir com fidelidade a landing page fornecida no desafio, respeitando os layouts para desktop e mobile. Os principais pontos trabalhados:

Layout limpo e responsivo
Ícones sociais alinhados corretamente
Ajustes de layout mobile usando @media queries
Tipografia e espaçamento conforme o design original

💻 Resultado
A landing page está funcional, responsiva e próxima ao design original proposto. Este projeto foi uma ótima oportunidade para reforçar habilidades de estruturação de layouts e atenção aos detalhes visuais.
